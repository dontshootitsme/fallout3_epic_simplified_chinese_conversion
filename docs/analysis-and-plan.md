## 二、什么格式 · 好不好改

### 格式 **[实测]**
- ESM 内部：24 字节记录头（`签名+大小+标志+FormID+8字节版本`）→ 子记录 `4字节签名 + 2字节长度 + 数据`；`GRUP` 分组头的 size 含自身头。
- **字符串 = 单字节、null 结尾、代码页 cp1252 的行内文本**，没有长度前缀、没有 UTF-16、没有外置字符串表。
- 约 4,200 条记录（主要是 `LAND` 与 **`NPC_`**）带 `flags & 0x00040000`，记录体是 **zlib 压缩**（前 4 字节是解压后长度）。**NPC 显示名就藏在这里**——用普通文本工具会整批漏掉 2,282 个 NPC 名字。
- BSA：`BSA\0` v104，**逐文件 zlib 压缩**，文件名以明文存在名字块里（12,280/12,280 全部解出）。

### 改动难度评级

| 维度 | 评价 |
|---|---|
| 读出文本 | **容易**。我已在你的机器上完成，100% 覆盖，0 解析错误。 |
| 写回文本 | **容易且已验证**。我的 `fo3_patch.py` 实测：32 条中文写入 `Zeta.esm` 副本，26 条命中普通记录 + 6 条命中压缩记录，长度字段（子记录→记录→各级 GRUP）全部联动修正，**结构自洽校验通过、逐条回读一致**。 |
| 让汉字**显示**出来 | **这是唯一的硬骨头**（见第三节）。 |
| 翻译**工作量** | 60–110 万汉字，是真正的时间成本。 |

演示产物：`fo3_localize\build\Zeta.esm`（含 32 条 GBK 中文，如 `废土客`、`莫里森·兰德博士`、`你在外星武器方面的训练经历使你成为了异星科技专家。`）。
⚠️ 它在装了中文字库+双字节插件之前**进游戏是乱码**，因为原版引擎不认双字节。

## 三、必须越过的三道门槛

### 门槛 1：Epic 版 exe 是 1.7.0.4，FOSE 不支持 → 必须降级
- **[实测]** `Fallout3.exe` FileVersion/ProductVersion = **1.7.0.4**，16,855,040 字节。
- **[官方]** FOSE 官网原文：*"2021-10-12 update (if you are seeing CRC = D32E228B errors): Bethesda has released an update labeled 1.7.0.4 … Use a downgrader for compatibility with the script extender and plugins."* 支持列表最高只到 **1.7.0.3**。
- **[社区]** 官方指定的降级器 = Nexus **24913 Fallout Anniversary Patcher**，描述明写支持 **Steam/GOG/Epic 的 GOTY 与普通版**，且降级后 `Fallout3.exe` 自动加载 FOSE（不需要 `fose_loader.exe`）。
- 后果：不降级 → 装不上 FOSE → 装不上中文字库插件 → 汉字必然乱码/方块。

### 门槛 2：引擎是单字节文本 → 需要双字节插件 + 中文字库
- **[实测]** `Fallout_default.ini` 的 8 个字体槽位 `sFontFile_1..8 = Textures\Fonts\*.fnt`，8 个 `.fnt` + 配套 `*_0_lod_a.tex/.dds` 全部在 `Fallout - Textures.bsa` 内，**全是拉丁字母字体，零 CJK 字库**。你的 `My Games\Fallout3\Fallout.ini` 同样。
- **[社区]** 解决方案是 FOSE 插件 **F3DC**（Nexus **15232**，"Fallout 3 Double Byte Character Plugin"，v1.5）：负责把 GBK 双字节正确切分并送进字库；配套 `F3DC.ini` 可改字体路径。
- 字库：汉化包把 `GB_*.fnt` + 大图集放进 `Data\Textures\Fonts\`，并把 ini 的 8 个槽位全部指过去；字库体积 16MB（简中）～32MB（繁中）。已知代价：显存占用高、老机器会卡。
- 文本编码：ESM 里写 **GBK**（字库前缀 `GB_` 与"完整 GBK 字库"的说法一致）。我的写入器已支持 gbk/big5/utf-8。

### 门槛 3：翻译量
3,790,075 个英文字符。人工翻译约 4–8 人周；纯机翻可数小时完成但需要术语表 + 后期校对，否则废土味全无。

## 四、三条可选路线

### 路线 A（推荐）：成熟汉化包 + 我的工具补漏
1. 降级 1.7.0.4 → 1.7.0.3（Anniversary Patcher）
2. 装 FOSE v1.3b2 + F3DC + 中文字库 + ButcherPete/Command Extender（现成汉化包通常自带）
3. 装 **Epic 兼容**的成品汉化：
   - 天邈&13号 v2.3（简中，[社区] 2024 知乎包以它为底本）
   - 甲午 2.0.2.2（2022-11-18，256MB，自带降级 exe 与 16M 字库）
   - 知乎《辐射3 2024年非官方汉化更新》（明确面向 Steam/Epic，含 FAP/FOSE/F3DC 步骤）
   - 词典路线 FOZH（Nexus 26653，明写"支援 Steam、GOG 以及 Epic"，不动 ESM，`[` 键即时中英切换）
4. **我的部分**：用已写好的普查器对成品包做"残留英文审计"，把漏译（已知重灾区：DLC 地名 `Bailey's Crossroads Metro`、`Outlook outpost`，部分武器装备名，电台字幕，获得任务弹窗）列成清单 → 我翻译 → 我的写入器出补丁 + 自动结构校验。

优点：1 天内可玩，风险最低，遇到"装完仍乱码"有社区排错资料。
缺点：译文风格不能定制；成品包本身有已知遗留问题（见附录）。

### 路线 B：全自研（我给你译）
1～2 同 A（字库/双字节插件仍必须装，这两步绕不过）。
3. 我用自己的管线：`fo3_extract.py` 出 64,535 行工作台 TSV → 我分批翻译（先 5,000 条 UI/名字/消息 → 5,600 条终端+笔记 → 37,556 条对话，约 20 批）→ `fo3_patch.py` 逐插件写回 → 自动校验 + A/B 文本对比报告 → 你拷进游戏验证。

优点：术语、称呼、语气完全可控；可只汉化 DLC 或某几类文本；每步都有字节级校验。
缺点：对话部分需要多轮长任务；文学性台词需要反复打磨。
建议：**先做 B 的"第一阶段"**（UI + 物品名 + 消息 + 终端菜单 ≈ 1.6 万条 / 35 万字符），你验收风格后再决定是否推进 37,556 条对话。

### 路线 C：只做词典式运行时替换
不碰 ESM，靠 F3DC/FOZH 在运行时查表替换。
优点：零风险、随时可关。缺点：覆盖率最低（任务获得弹窗、含变量的长句、上下文相关的同词多义都换不了）。

## 六、风险与回滚

| 风险 | 缓解 |
|---|---|
| 降级 exe 影响存档 | 存档在 `My Games\Fallout3\Saves`，降级不动它；仍先整体备份。社区无人报告存档损失，但也无人书面承诺 **[社区·存疑]** |
| 汉化包与你的 DLC 组合有冲突（已知：Zeta 结局不爆炸、赏金猎人物品导致 CTD） | 先只启用 6 个官方 master 测试，再逐个加 |
| 大显存字库导致卡顿 | 换 16M 精简字库；可用 `BandList.Txt` 按码位裁剪 |
| 我的补丁改坏 ESM | 只读原文件、产物写到 `build\`；每次写完自动做「完整重遍历 + 长度自洽 + 回读比对」；你手动替换前原文件仍在 |
| Epic 启动器绕过 FOSE | 降级后用根目录 `Fallout3.exe` 启动，不要用 `fose_loader.exe`；需要更新 DLC 时临时用原版 exe |
