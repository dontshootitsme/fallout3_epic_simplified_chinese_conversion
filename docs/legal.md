# 版权与分发须知

**这不是法律意见。** 动手前先想清楚这三层。

## 1. 游戏本身

本仓库不含任何 Bethesda / ZeniMax 的文件：没有 `.esm`、`.bsa`、贴图、音频、exe，
也没有从游戏里导出的英文原文。任何人都需要**自己合法拥有**《Fallout 3: GOTY》
（Epic / Steam / GOG 均可），再用本工具从**自己的安装**里生成工作台。

`fo3zh extract` 生成的 `workbench.tsv` 里含有Bethesda 的英文原文。那是你本地生成物，
**不要把它提交进公开仓库或贴到公开地方** —— `.gitignore` 已经默认排除它。

## 2. 译文

对游戏文本的翻译在著作权法上属于**衍生作品**，严格说需要权利人许可。
现实中游戏汉化补丁作为玩家社区产物被广泛分发（Nexus Mods 上大量存在），
Bethesda 对《辐射3》这类老游戏的社区汉化也长期默许，但**"默许"不等于"授权"**：
平台可以下架，权利人可以要求停止。

务实做法：

* 优先只提交**译文表**（`formid,nth,rectype,sub,zh`），不含英文原文 —— 体积小、
  也少复制了原文；
* 发布时挂"粉丝作品、非商业、不含游戏资产、可按要求下架"的声明；
* 不要收费、不要打包游戏本体、不要去掉了原作者署名。

## 3. 第三方运行时（FOSE / F3DC / 成品汉化包）

* **FOSE**（Script Extender）与 **F3DC** 各有自己的许可与分发渠道（fose.silverlock.org、
  Nexus 15232），本仓库不镜像、不重新分发；
* 别人的成品汉化包（天邈&13号、甲午、知乎 2024 更新等）**署名与授权归原作者**，
  不要改名当自己的发；引用请写清来源与版本。

## 4. 修改自己买的游戏

在多数司法辖区，为自己在已购设备上做本地化属于可接受的私人使用；
但**分发**修改后的官方 `.esm` 文件（哪怕只是把中文写进去）等于分发被修改的权利人文件，
风险高于只分发"译文表 + 本地生成"。因此本工具链默认：
**产物只写到你自己的磁盘，仓库只放代码与译文。**
